## 一句话定义
关于互联网应构建在原生 App 还是 Web 上的历史争论；其本质不是技术路线之争，而是商业模式与生态控制权之争。

## 展开解释
- **乔布斯的路线**：痛批 Flash（占资源、需升级、易出问题、让网页生态被一家公司垄断），倾向 HTML；但苹果最终选择 App。当时正处于人们从电脑转向手机的"时代交汇点"，不应继承 PC 时代的缺陷。
- **扎克伯格的路线**：执意押注 HTML 是因为跨多平台（塞班/MeeGo/黑莓/Windows Phone）定制开发成本高，且对 App Store/Play Store 的中心审核与内购抽成充满戒心。该决策最终被他称为"我们犯下的最大错误"。
- **结局**：App 派看似赢了，但 Facebook 的 Web 投入留下 React / React Native，模糊了 App 与 Web 的界限。
- **新战事**：AI 与 Agent 时代，操作信息的方式（MCP/WebMCP 介入浏览器）可能让主场从手机切回电脑，新一轮 App/Web 之争开始。
