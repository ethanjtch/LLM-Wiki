## 核心论点
App 与 Web 之争的基础不全是技术，很大部分是**商业模式与生态**之争。平台为了圈住流量而制造封闭，导致链接死亡、截图成为主流传播方式；而现在 Agent 可能正在摧毁这十年 App 构建起来的生态，新一轮 App/Web 之争开始了。

## 要点摘录

### 历史上的两次"站队"
- 乔布斯痛批 Flash、倾向 HTML，但苹果最终走向了 App；扎克伯格执意押注 HTML，最终也走向了 App，并称其为"我们犯下的最大错误"。
- 苹果的理由：Flash 占资源、需不断升级、易出问题，且会让网页生态被一家公司掌控；手机时代不应继承 PC 时代的缺陷。
- Facebook 押注 HTML 的动机：多平台（塞班、MeeGo、黑莓、Windows Phone）定制开发成本高，且对 App Store / Play Store 的审核与抽成机制充满戒心。
- Facebook 的 Web 投入留下遗产：React、React Native 模糊了 App 与 Web 的界限。

### 封闭生态与"链接的死亡"
- 当平台**不想信息流入**：关掉链接预览（X）、屏蔽链接（微信）、折叠分享口令（微信）。
- 当平台**不想信息流出**：在分享菜单动手脚（微信）、屏蔽文件打开方式、阻止内容被解析（X article）。
- 当平台**需要流量**：让用户随手一跳转到自家平台（淘宝、京东）、设置内容仅 App 内可看。
- 结果：不受平台控制的**图片（截图）**成为信息传播主流——虽然不可搜索、不可复制、难以溯源，但规避了平台人为制造的门槛。

### Agent 时代：主场切回电脑
- 豆包等产品显示智能体急于接管下一代互联网形态；Agent 正以 MCP / WebMCP 等方式介入浏览器、直接操作信息。
- 作者判断：手机作为载体在严肃任务上越来越吃力（屏幕小、页面化系统操作、跨 App 交互困难），可能将出现新形态，或先回到电脑。
